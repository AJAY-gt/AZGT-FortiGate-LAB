# AZ-FortiGate-LAB

Purpose:  
This lab is designed to simulate a multi‑site enterprise network using a hub‑and‑spoke architecture built on FortiGate firewalls and supporting routers. It demonstrates secure inter‑site connectivity, dynamic and static routing, segmentation, and centralized management using FortiManager. The environment includes dual‑WAN paths, multiple hub firewalls, spoke sites, and LAN segments, allowing hands‑on validation of VPN design, failover behavior, traffic flow, and security policy enforcement across distributed networks.

Technologies Used

Proxmox VE – Virtualization platform hosting the lab environment

EVE‑NG – Network emulation platform for multi‑vendor topologies

Cisco IOL – Lightweight Cisco routing and switching images

FortiGate (FortiOS 7.0.15) – Firewall, routing, VPN, and security policies.

FortiManager – Centralized management and policy control
